# 매일의 온도

일정과 하루의 기분을 기록하는 한국어 모바일 캘린더입니다. Capacitor로 Android와 iOS에서 같은 달력 화면을 사용하고, 기기 알림·공유·‘다음 일정’ 위젯을 각 운영체제와 연결합니다. 일정과 기분은 해당 기기에 저장됩니다. 기기를 옮길 때는 달력 아래의 **백업·복원**을 사용하세요.

## 실행

Node.js 22.12 이상과 npm을 사용합니다. 프로젝트 폴더에서 실행하세요.

```sh
npm ci
npm run dev
```

브라우저에서 단독으로 열 수 있는 파일은 `npm run preview:file`로 만듭니다. 결과는 `release/매일의 온도.html`입니다. 기기 알림과 시스템 위젯은 모바일 앱에서 동작합니다.

### 아이폰에서 웹으로 테스트

PC와 아이폰을 같은 Wi-Fi에 연결하고, PC에서 `npm run preview:file` 후 `npm run preview:phone`을 실행하세요. 터미널에 나온 주소를 아이폰 Safari로 엽니다. 서버는 완성된 달력 페이지만 제공합니다. PC와 Safari에 입력한 일정은 각각 그 브라우저에 저장됩니다. 테스트 서버는 터미널에서 Ctrl+C로 종료할 수 있습니다.

PC 브라우저에서는 390px 폭의 세로 화면으로, 휴대폰에서는 기기 너비에 맞춰 표시합니다. **설정 → 화면 모드**에서 밝게·어둡게·기기 설정을 선택할 수 있으며 처음 열 때는 밝게 표시합니다.

현재 화면 모드는 상단 **설정** 안에 있습니다. 같은 설정에서 달력의 세로 연속 스크롤·좌우 이동, 날짜별 목록의 상시 표시·누를 때 표시, 날짜 칸에 보여줄 일정 수를 고릅니다. 처음에는 세로 스크롤과 누를 때 표시를 사용합니다.

월간에서 날짜를 누르면 아래에 그날 일정이 열립니다. 목록의 **이 날짜에 일정 추가**로 등록하거나, **날짜 선택**으로 떨어진 날짜를 여러 개 고른 뒤 하단 버튼으로 한 번에 등록할 수 있습니다. 일정 제목은 상세 화면을 열며, 반복 일정 편집 시 이번 회차·이후·전체를 선택합니다. 등록 창에서 종료 날짜와 복수 알림을 지정할 수 있습니다.

## 모바일 빌드

공유 화면이나 네이티브 설정을 변경한 뒤 `npm run sync`를 실행합니다. 이 명령은 웹 자산을 빌드해 Android와 iOS 프로젝트에 복사하고 위젯과 광고 설정을 적용합니다.

- **Android** — Android SDK 36과 JDK 21을 준비하고 `npx cap open android`로 Android Studio에서 실행합니다. 현재처럼 폴더 경로에 한글이 포함된 Windows 환경에서는 `android` 폴더에서 `.\gradlew.bat -Pandroid.overridePathCheck=true assembleDebug`로 테스트용 APK를 생성합니다.
- **iPhone** — Mac에서 `npx cap open ios`로 Xcode 프로젝트를 엽니다. 앱과 NextEventWidget에 Apple 개발 팀을 지정하고 양쪽에서 `group.app.maeilon.calendar` App Group을 사용하도록 서명합니다.
- **이름과 식별자** — 현재 앱 식별자는 `app.maeilon.calendar`, 위젯 식별자는 `app.maeilon.calendar.next`입니다. 스토어 등록 시 보유한 식별자로 변경한다면 앱 그룹과 위젯 설정도 함께 갱신하세요.

## 잠금화면

**잠금화면** 탭에서 월간 달력·이번 주 시간표·오늘 시간표·다음 일정을 골라 PNG로 저장한 뒤 휴대폰의 배경화면 설정에서 선택하세요. 배경화면은 저장 당시의 일정입니다. 기분 이모지 표시 여부와 라벨 필터를 내보내기 전에 고를 수 있습니다.

**다음 일정**은 별도의 시스템 위젯입니다. iPhone에서는 잠금화면을 편집해 위젯을 추가합니다. Android에서는 위젯 선택 화면에서 추가하며, 잠금화면 배치 가능 여부는 기기에 따라 다릅니다. 앱은 앞으로 표시할 일정 최대 64건을 기기에 전달합니다. 반복 알림은 기기 예약 한도를 고려해 가까운 알림 60건까지 예약하고 앱을 열거나 일정을 바꾸면 갱신합니다.

## 광고와 배포

일반 빌드는 광고 단위를 설정한 플랫폼에서만 배너를 요청합니다. AdMob에서 앱과 하단 배너 광고 단위를 만든 뒤 아래 환경 변수를 설정한 셸에서 `npm run sync`를 실행합니다. 테스트 배너는 `npx vite build --mode development` 후 `npx cap copy`로 확인할 수 있습니다.

| 플랫폼 | AdMob 앱 ID 환경 변수 | 배너 단위 ID 환경 변수 |
| --- | --- | --- |
| Android | `ADMOB_ANDROID_APP_ID` | `VITE_ADMOB_ANDROID_BANNER_ID` |
| iOS | `ADMOB_IOS_APP_ID` | `VITE_ADMOB_IOS_BANNER_ID` |

출시 전 개발자 계정에서 실기기 알림 수신, 일정 변경 후 위젯 갱신, 배경화면 저장, 광고 동의 흐름을 확인하세요. Google Play 배포본은 보유한 업로드 키로 서명하고, iPhone 배포본은 Apple 개발 팀에서 아카이브해 TestFlight로 확인할 수 있습니다.
